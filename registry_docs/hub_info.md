# hub_info

Return hub service metadata and a summary of registered edge devices. This does not call a device.

## Parameters

| Name | Required | Meaning |
|---|---|---|
| — | — | This call takes no model arguments. |

## Cases

### Typical call

Input:

```json
{}
```

Output:

```json
{
  "success": true,
  "result": "completed"
}
```
